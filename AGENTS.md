# Правила для разработки

- Не использовать символ длинного тире (U+2014) ни в коде, ни в текстах интерфейса, ни в документации. Вместо него: дефис, двоеточие, точка или «·».
- Сохранять данные пользователя при любых изменениях схемы IndexedDB и каталога: только новые версии в `src/db/schema.ts`, без удаления старых.
- Не менять числовые `id` упражнений в `data/exercises.json`: на них ссылаются сохраненные подходы.
- Весь текст интерфейса брать из `src/i18n/translations.ts`, для русского и английского.
- Касательные цели не меньше 44×44 CSS px, контраст по WCAG AA, учитывать `prefers-reduced-motion`.
- Иллюстрации упражнений класть в `public/exercises` в WebP, 640×640, и регистрировать в `src/components/mastery/exerciseArtwork.ts`.
- Перед отправкой: `npm test`, `npm run lint`, `npm run build`.
