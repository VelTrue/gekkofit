# Локальная админ-панель

Запуск из каталога приложения:

```powershell
npm.cmd run dev -- --host 127.0.0.1
```

Откройте адрес сервера, затем «Настройки» > «Админ-панель (локальная)».
Панель доступна только в режиме разработки и на loopback-адресе.
Условный импорт через `import.meta.env.DEV` исключает панель и модуль
редактирования из production-сборки `npm.cmd run build`.
Это локальный инструмент владельца компьютера, без аккаунтов и серверной роли администратора.

Выберите упражнение и задайте уровень или количество очков. Выбор уровня
подставляет его нижний порог. Кнопка сохранения записывает корректировку
в IndexedDB текущего браузера. Новые выполненные подходы продолжают приносить
очки. История тренировок, рекорды и реальные показатели не изменяются.
«Вернуть автоматический расчёт» убирает корректировку выбранного упражнения.

Корректировки включаются в экспорт данных. Старые резервные копии без этого
поля по-прежнему поддерживаются. Данные разных адресов, браузеров и устройств
хранятся отдельно.
